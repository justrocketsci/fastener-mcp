# Data and geometry provenance

Original Fastener MCP recipes are written for this project using CadQuery/OpenCascade. Dependency licenses remain with their respective packages.

Selected numerical dimensional facts are attributed to **BOLTS**, Johannes Reinhardt, from `hex.blt`, `hex_socket.blt`, and `washer.blt`, revision `05a2acd1f77737789a313b4c77f1f8eea35da256` of https://github.com/boltsparts/BOLTS_archive. Those source files declare **GNU LGPL 2.1 or later** (https://www.gnu.org/licenses/old-licenses/lgpl-2.1.html). We did not copy their CAD generation code. The imported historical MIT label is not relied upon for current data.

Bolt Depot and Monster Bolts sources provide linked, checked product facts and dated price observations. Böllhoff's HELICOIL Plus catalog provides linked dimensional and installation facts; the manufacturer's document, drawings and marketing text are not redistributed. HELICOIL is a Böllhoff product identity, not a generic label for every insert.

No restricted standards document is included. Naming a standard describes the source's reference; it is not a certification of the generated model or a grant of rights over that standard. See `data/catalog/sources.json` for per-source usage notes and precise locators.
